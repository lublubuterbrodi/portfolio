# Portfolio

A modern, responsive portfolio website built with **Next.js**, showcasing my projects, skills, and experience as a Frontend Developer.

## Preview

> Live Demo: https://portfolio-red-two-ybt2zzle4d.vercel.app/

## Features

- Modern and responsive design
- Clean UI inspired by Apple & Linear
- Smooth animations with Framer Motion
- Interactive project showcase
- Downloadable CV
- Contact section with social links
- Optimized for desktop, tablet, and mobile devices

## Projects

### Diet Tracker

A nutrition tracking application built with Next.js.

- Personalized diet plans
- Daily meal tracking
- Weight monitoring
- Product search
- Authentication with NextAuth
- Neon PostgreSQL database

### Telegram Content Bot

A Telegram bot that delivers categorized educational content.

- Category-based content delivery
- Telegram Bot API

A Telegram-based manga reading platform featuring:

- Premium chapters
- Achievement system
- Virtual currency
- Reading progress
- Telegram Bot API

## Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/portfolio.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
